# Z Assistant

Personal task, idea and priority app for Zee. Installable PWA: works offline, saves on the phone, backup and restore built in.

Live: https://xeeshanwolf.github.io/z-assistant/

## Files
- `index.html` the whole app
- `sw.js` offline worker. Bump `VERSION` on every change so phones pick up the update.
- `manifest.json`, `icons/`, `fonts/` install name, home-screen icons, offline fonts

## Planned upgrades
- Sync across phones (Supabase or Firebase)
- Push reminders that arrive when the app is closed
